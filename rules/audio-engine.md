# Regra: Motor de Áudio e Integrações (VolumeMax)

## 1. Arquitetura de Volume e Boost
- **Faixa de 0% a 100%:**
  - O volume deve ser controlado diretamente pelo subsistema de áudio mestre do Windows via CoreAudio (`VolumeBridge.exe set-volume`).
  - O ganho no Equalizer APO deve ser fixado em `Preamp: 0.0 dB`.

- **Faixa de 101% a 500% (Super Boost):**
  - O volume mestre do Windows deve ser fixado em `100%` (`1.0`).
  - A amplificação real deve ser aplicada instantaneamente no arquivo de configuração do Equalizer APO:
    - **Caminho Padrão:** `C:\Program Files\EqualizerAPO\config\config.txt`
    - **Fórmula de Decibéis:** $dB = 20 \cdot \log_{10}(\text{boostLevel} / 100)$
    - **Formato Escrito:**
      ```text
      # Generated by VolumeMax Windows Booster
      # Gain corresponding to [LEVEL]%
      Preamp: +[GAIN_DB] dB
      ```
    - Exemplos de referência:
      - 100% $\to$ `0.0 dB`
      - 150% $\to$ `+3.5 dB`
      - 200% $\to$ `+6.0 dB`
      - 300% $\to$ `+9.5 dB`
      - 500% $\to$ `+14.0 dB`

## 2. PROIBIÇÃO ABSOLUTA do FxSound
- **É ESTRITAMENTE PROIBIDO** reinstalar, reintroduzir referências, chamadas de processo, placas de som virtuais ou dependências do **FxSound**.
- O projeto opera exclusivamente com o **Equalizer APO** integrado ao driver de som do Windows.

## 3. Controle por Aplicativo (Per-App Audio)
- As sessões individuais de aplicativos continuam sendo gerenciadas pelo módulo C# nativo (`VolumeBridge.exe sessions`, `set-app-volume <pid> <vol>`) via interfaces WASAPI `IAudioSessionEnumerator` e `ISimpleAudioVolume`.
